# NewerWin — Lua-скрипты

Документация по скриптам на Lua для клиента **NewerWin** (Minecraft 1.21.11, Fabric) и готовый
промт, по которому любая нейросеть напишет тебе скрипт.

> Сам не программируешь? Это нормально — для того здесь и лежит [`PROMPT.md`](PROMPT.md).

## Быстрый старт: скрипт через ИИ за 2 минуты

1. Открой [`PROMPT.md`](PROMPT.md) и нажми **Raw** → скопируй весь текст
   (или кнопку «Copy raw file» справа сверху).
2. Вставь его в чат с ИИ: ChatGPT, Claude, Gemini, DeepSeek — подойдёт любая.
3. В самом конце, под заголовком **«Задача»**, опиши, что нужно. Чем конкретнее, тем лучше:
   - что делает скрипт;
   - какие настройки нужны (переключатели, ползунки, цвет);
   - нужна ли HUD-панель, где она стоит, как выглядит;
   - на какой клавише или команде он запускается.
4. Отправь. ИИ ответит готовым кодом и скажет, как назвать файл.
5. Сохрани код в файл `имя.lua` в папке скриптов (см. ниже) и включи скрипт.

### Примеры задач для ИИ

- «Панель в углу экрана: мои координаты, направление и FPS, цвет текста настраивается.»
- «Когда моё здоровье падает ниже N сердец, проигрывать звук и показывать title „ЛЕЧИСЬ“. N — ползунок.»
- «Подсвечивать сундуки и шалкеры в радиусе 20 блоков рамкой в мире, цвет в настройках.»
- «Команда `.calc 2+2*3`, которая считает выражение и пишет ответ в чат.»
- «Если в чат пришло сообщение со словом „аукцион“, присылать уведомление клиента.»
- «Над каждым игроком писать его HP и расстояние до него.»
- «По нажатию клавиши R писать в чат `/home`, не чаще раза в 5 секунд.»

### Если скрипт не заработал

Скопируй ИИ текст ошибки из уведомления «Ошибка скрипта: …» (или из `.scripts list`) и напиши:
«Скрипт выдал ошибку: <текст>. Исправь.» Если что-то работает не так, как задумано, опиши,
что именно происходит. Промт уже у ИИ в контексте, повторно его вставлять не нужно.

## Где лежат скрипты и как их включать

Папка скриптов:

| Система | Путь |
|---|---|
| Windows | `C:\newerwin\scripts` |
| Linux / macOS | `~/newerwin/scripts` |

Точный путь покажет команда в игре: `.scripts dir`.

- Каждый файл `*.lua` в этой папке — отдельный скрипт. Имя скрипта = имя файла.
- Скрипты появляются в ClickGUI в разделе скриптов; там их включают и настраивают.
- Команды в чате (`.lua` и `.script` тоже работают):

| Команда | Что делает |
|---|---|
| `.scripts` или `.scripts list` | список скриптов и их состояние (вкл / выкл / ошибка) |
| `.scripts reload` | перечитать папку (после добавления или правки файла) |
| `.scripts enable ИМЯ` | включить скрипт |
| `.scripts disable ИМЯ` | выключить скрипт |
| `.scripts set ИМЯ НАСТРОЙКА ЗНАЧЕНИЕ` | изменить настройку скрипта из чата |
| `.scripts dir` | показать путь к папке скриптов |

Поправил файл — сделай `.scripts reload`. Если в скрипте ошибка, он выключается
и показывает уведомление с текстом ошибки.

## Что умеют скрипты

Полный справочник лежит в [`PROMPT.md`](PROMPT.md): его же читает ИИ. Коротко, скрипт может:

- реагировать на события: тик, отрисовка HUD и мира, клавиши, чат, пакеты, здоровье, таб-лист;
- рисовать HUD (панели, текст, градиенты, иконки, предметы, размытие) и рамки/линии в мире;
- создавать свои настройки в GUI и перетаскиваемые элементы HUD;
- читать мир (сущности, блоки, биом, погода, луч взгляда) и своего игрока;
- работать с инвентарём, поворачивать голову, управлять движением и клавишами;
- включать модули клиента и менять их настройки, работать с друзьями, staff-листом, пати;
- регистрировать свои команды `.имя`, хранить данные между запусками, обмениваться
  сообщениями с другими скриптами, управлять Baritone.

## Ограничения

- Движок LuaJ = **Lua 5.2**: нет `//`, битовых операторов (есть `bit32`), `utf8`.
- Нет доступа к файлам вне личной папки скрипта, нет `io`, `require`, `os.execute`.
- Скрипт не может блокировать игру ожиданием: задержки делаются через таймеры.
- Работает в клиенте NewerWin; в других модах и клиентах этого API нет.
